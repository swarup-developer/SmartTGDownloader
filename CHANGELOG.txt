Version: 2.1.0 / 8.8.0
Build/Version Code: 5 / 8.8.0 (Android 2.1.0 / Windows 8.8.0)
Release Date: September 12, 2026
========================================================================

SUMMARY OF CHANGES:
Android adds live per-file download progress, release-APK signing via CI
secrets, and a persisted download-history tab with open/re-download/filter.
Windows v8.8.0 shipped the native-compiled lightweight build.

[ADDED]
- Android: live per-file download progress in the results sheet, driven by
  TDLib's UpdateFile stream (per-row bars, per-file byte counters, overall
  summary bar, completion checkmarks).
- Android: release APK signing loaded from keystore.properties / CI secrets
  (ANDROID_KEYSTORE_B64, ANDROID_KEYSTORE_PASSWORD, ANDROID_KEY_ALIAS,
  ANDROID_KEY_PASSWORD) with a safe unsigned fallback.
- Android: download history tab persisted with Room - completed downloads
  survive restarts, with open-file (FileProvider) and re-download actions
  plus filter chips by category or source channel.

[CHANGED]
- Windows packaging replaced Nuitka with Cython (.pyd compilation) +
  PyInstaller onefile; released as v8.8.0 with a ~25 MB portable exe.

[FIXED]
- Windows build pipeline: uv sync now installs the build dependency group,
  Cython 3.1 directive compatibility, versioned .pyd handling, and
  absolute --add-data paths for PyInstaller.

Version: 2.0.0 / 8.8.0
Build/Version Code: 4 / 8.8.0 (Android 2.0.0 / Windows 8.8.0)
Release Date: September 11, 2026
========================================================================

SUMMARY OF CHANGES:
This release fixes a stale scan-cache bug on Windows and completely rebuilds
the Android client natively in Kotlin + Jetpack Compose, removing Flutter.

[ADDED]
- Native Android app: rebuilt from scratch in Kotlin with Jetpack Compose
  (Material 3), Coroutines/StateFlow architecture, and TDLib for Telegram.
- TDLib integration: prebuilt native distribution (all ABIs) downloaded and
  SHA-256-verified at build time - no NDK/CMake setup required.
- Android scan pipeline: link analysis with monotonic scan tokens so results
  from a previous link can never repopulate the results sheet.
- Telegram API credentials are now injected via gradle.properties / CI
  secrets instead of being embedded in source.

[FIXED]
- Windows stale scan cache: analyzing a second link could reuse the previous
  scan's cached results; pending_scan is now invalidated on every new scan,
  cancellation, and dialog close.
- Windows scan race: concurrent scans are arbitrated by scan tokens so an
  older scan can no longer overwrite or report for a newer request.
- Windows offline check now probes a Telegram host instead of api.github.com,
  so VPN/proxy users blocking GitHub are not falsely reported offline.
- Download progress dialog stop action now drops cached scan results.

[REMOVED]
- Flutter Android client (android_flutter/), including all Dart code, Flutter
  runner projects (linux/macos/web/windows), and pubspec-based dependencies.
- Windows MSIX packaging script's Flutter/dart-msix dependency chain.

[BUILD CHANGED - Windows]
- Dropped Nuitka (2.8.9) and numpy from the build toolchain: Nuitka was
  extremely heavy (long compiles, huge memory use, slow release pipeline).
- New lightweight pipeline: Cython compiles all app modules
  (utils/worker/ui) to native .pyd machine-code binaries, then PyInstaller
  packages a single-file exe. No readable .py source or .pyc bytecode for
  app modules ships in the released executable.

[VERIFICATION]
- Windows: Python syntax check clean on all modified modules.
- Windows: local build of dist/SmartTGDownloader.exe verified.
- Android: fresh Gradle project pinned to AGP 9.3.2 / Kotlin 2.4.20 /
  Compose BOM 2026.09.00 / Gradle 9.7.1 (assembleDebug and assembleRelease
  build successfully locally; Android release is deferred until testing).

SUMMARY OF CHANGES:
This release introduces a fully automated GitHub CI/CD workflow,
fixes a critical Telegram verification login hang bug, implements a mandatory
in-app update check and installer system for both Android and Windows platforms,
and reorganizes the Git repository branch structures.

[ADDED]
- GitHub CI/CD Actions: Created separate, automatic release workflows for Windows (Nuitka compilation) and Android (App Bundle AAB and 3-ABI splits APK packaging) triggered on branch pushes.
- Mandatory In-App Update (Android): Startup check against GitHub Releases API, modal update dialog with release notes, and background downloader with MethodChannel-launched system package installer.
- Mandatory In-App Update (Windows): wxPython update dialog, background file downloader, and self-replacing batch script sequence to swap binary and auto-restart.
- Clean Git Setup: Consolidated remote repository link and structured branches (main, windows, android) matching the modular folder layout.

[FIXED]
- Telegram login verification hang on Android: Added onClose socket connection resets to prevent dead socket reuses, along with a 15-second API invoke timeout safety net.
- Windows build script CI compatibility: Patched build.bat to bypass pause commands during GitHub Action runners.
- Clean Root Directory: Merged remote history while purging redundant/old duplicate root files, keeping the workspace structured.

[VERIFICATION]
- Unit & Widget Test Suites: 100% Passing.
- Static Code Analysis: 100% Clean.
- CI/CD Builds: Active workflows verified on remote branch pushes.
